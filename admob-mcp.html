プライバシーポリシー

admob-mcp（以下「本ツール」）は、babyloos（以下「開発者」）が自身のAdMobアカウントの収益レポート・広告ユニットを参照・管理するために使用する個人用ツールです。第三者への提供は行っていません。

1. 取得する情報

本ツールは、Google OAuth により許可された範囲で、開発者自身の AdMob アカウントのアプリ情報・広告ユニット情報・収益レポートを AdMob API から取得します。

2. 情報の利用目的

取得した情報は、開発者自身のアプリの収益分析および広告設定の管理にのみ使用します。

3. 情報の保存と第三者提供

認可トークンは開発者のPC内にのみ保存されます。取得した情報を第三者に提供・販売することはありません。
